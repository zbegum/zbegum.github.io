The idea

The genetic code is degenerate — 61 codons encode only 20 amino acids. Leucine alone has 6 synonymous codons (TTA, TTG, CTT, CTC, CTA, CTG) that all produce the exact same protein. This redundancy is an invisible information channel.

By choosing which synonymous codon to use at each position, we hide binary data inside a functional gene. The bacteria grow normally. The protein folds and glows green. The message is invisible unless you know to look — and have the metadata key.

Every different message produces a different DNA sequence — typically ~22% of codons change between messages. But the protein is always identical. The ribosome doesn't care which Leucine codon you chose. Your decoder does.

How it works — interactive walkthrough

The genetic code has 64 codons but only 20 amino acids. Many amino acids have multiple synonymous codons — these are the wobble positions where we can hide bits.

Formula: bits per position = floor(log₂(number of codons)). sfGFP has 231 wobble positions → total capacity 341 bits ≈ 42 bytes.

Your message is Huffman-compressed into a bit stream. Then we walk through sfGFP amino acid by amino acid, consuming bits and choosing codons.

The same bit stream mapped to the same positions always produces the same codons. If those codons happen to create a long homopolymer run, Twist rejects the sequence. Bit rotation fixes this.

Encoding pipeline
  • 01Compress with Huffman coding — builds a variable-length prefix code from byte frequencies. Short messages compress to fewer bits.
  • 02Scan sfGFP amino-acid by amino-acid. At each position, count synonymous codons in E. coli. If n codons exist, ⌊log₂(n)⌋ bits can be hidden here. Total capacity: 341 bits.
  • 03Map bits → codons. Read ⌊log₂(n)⌋ bits from the stream; use the integer value as an index into the sorted codon list.
  • 04Bit rotation. Try all offsets; pick the one that minimises the longest homopolymer run. Store chosen offset in metadata.json.
  • 05Output the 729 nt insert (NdeI + sfGFP CDS + XhoI). Order from Twist, clone into pET-28a (NdeI / XhoI), transform E. coli BL21(DE3). Induce with IPTG.
